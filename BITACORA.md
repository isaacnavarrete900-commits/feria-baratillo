# Bitácora del Proyecto - Feria El Baratillo

## Ejercicio 1 - Modificación de la Velocidad

Se modificó la variable:

let velocidad = 1;

por:

let velocidad = 3;

### Observaciones

- El texto se movió mucho más rápido.
- En algunos momentos parecía desaparecer parcialmente del canvas debido a la velocidad del desplazamiento.
- El rebote ocurrió más bruscamente.

### Prueba adicional

También se probó:

let velocidad = 0.5;

Resultado:
- El movimiento fue extremadamente lento.
- Por momentos parecía que el texto estaba detenido.
- El desplazamiento fue más suave.

# Glosario de Términos

## HTML
Lenguaje utilizado para crear la estructura de una página web.

## CSS
Lenguaje usado para diseñar y dar estilos visuales a una página web.

## JavaScript
Lenguaje de programación que permite agregar interactividad y funciones dinámicas.

## Canvas
Elemento de HTML que permite dibujar gráficos y animaciones mediante JavaScript.

## DOM
Estructura que representa los elementos de una página web y permite modificarlos dinámicamente.

## Evento onclick
Evento que se ejecuta cuando el usuario hace clic sobre un elemento.

## Función
Bloque de código reutilizable que realiza una tarea específica.

## Variable
Espacio donde se almacena información que puede cambiar durante la ejecución del programa.

## Animación
Movimiento o cambio visual generado continuamente en la interfaz.

## requestAnimationFrame()
Método de JavaScript utilizado para crear animaciones fluidas en el navegador.

## Hover
Efecto visual que ocurre cuando el cursor pasa sobre un elemento.

## transition
Propiedad de CSS que suaviza cambios visuales entre estados.

## Git
Sistema de control de versiones utilizado para guardar cambios en proyectos.

## GitHub
Plataforma online donde se almacenan y comparten repositorios Git.

## Commit
Registro o punto de guardado de cambios realizados en un proyecto.

## Repositorio
Espacio donde se almacena el proyecto y su historial de cambios.

## GitHub Pages
Servicio de GitHub que permite publicar páginas web online.

## Responsive Design
Diseño adaptable a diferentes tamaños de pantalla.

## Parámetros
Datos enviados a una función para que pueda trabajar con información específica.
